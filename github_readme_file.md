# 🪙 Coin Knight

**Coin Knight** is a fun, classic 2D platformer made with the **Godot Engine**. You play as a brave knight exploring a land filled with dangerous slimes and hazards. Your objective is simple: **collect all the coins in the level to win!**

---

## 🎮 How to Play

* **Objective:** Explore the map and pick up every coin.
* **Victory:** Collecting all coins displays the victory message and completes the run.
* **Hazards:** Watch out for bouncing green slimes, shooting purple slimes, and deadly pits! Hitting any hazard or falling off the map will force you to restart.

## 📥 How to Run the Desktop Version

### Prerequisites
To run the game binary from this repository, you need to have **Godot Engine** installed on your system.

#### Step-by-Step Instructions to Download Godot Engine:
1. Visit the official website: **[godotengine.org/download](https://godotengine.org/download)**
2. Choose your operating system (**Windows**, **macOS**, or **Linux**).
3. Download **Godot 4.x** (Standard version).
4. Godot comes as a portable `.zip` file—simply extract it to a folder of your choice. No setup executable or installation wizard is needed!

---

### Running the Game

1. Download the **`Coin_Knight.7z`** archive file from this repository.
2. Unzip the `.7z` file using an archive utility like [7-Zip](https://www.7-zip.org/) or [WinRAR](https://www.win-rar.com/).
3. Launch the extracted game application executable.
4. Enjoy playing **Coin Knight**!
